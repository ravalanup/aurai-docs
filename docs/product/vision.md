# Vision and positioning

## Problem
Teams across Amazing-Enterprise want to use AI, and many already do, but each in their own way: separate vendor accounts, copied data pasted into public tools, one-off scripts with embedded API keys, and prototypes that never reach production because nobody can answer basic questions about safety, cost and ownership.

The result is duplicated spend, uneven risk, and a long gap between a good idea and a trusted, supported product.

## Vision
Every team at Amazing-Enterprise has one governed path from idea to production AI: the same entry point, the same controls, the same measurements, whatever model or tool sits behind it.

## Positioning
**For** business and technology teams across Amazing-Enterprise **who** need to turn AI ideas into dependable products, **Aurai is** the enterprise AI platform **that** provides one gateway, workspace, agent runtime, knowledge layer and governance process. **Unlike** teams buying and building separately, **Aurai** makes the safe path the easy path and makes AI usage observable, governable and measurable.

## Principles
1. **Safe by default.** Governance is part of the platform, not a review at the end.
2. **Model-agnostic.** No team is locked to a vendor; the gateway absorbs change.
3. **Grounded.** Answers cite company knowledge and respect who may see what.
4. **Humans decide.** Agents that act on systems pass through approval gates matched to risk.
5. **Measured.** Every use case has success metrics, cost visibility and quality evidence.
6. **Self-service first.** Teams should reach their first working use case without filing a ticket.

## What Aurai is not
- Not a replacement for domain applications. It is the layer they build on.
- Not a model provider or a model training platform.
- Not an unrestricted sandbox. Every use case sits in a risk tier with matching controls (see [risk tiers](../governance/risk-tiers.md)).
