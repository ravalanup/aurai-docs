# Personas

Personas are defined by function. They describe the needs the platform is designed around.

| Persona | Typical role | Needs from Aurai | Primary surfaces |
|---|---|---|---|
| **Experience Operations Lead** | Parks and resorts operations | Quick answers from operating procedures and incident history; summaries of daily reports; safe automation of routine coordination | Workspace, Knowledge, Workflows |
| **Content and Production Producer** | Studios and production | Search and summarize internal scripts, schedules and asset metadata under strict IP controls; assistive drafting | Workspace, Knowledge, Gateway |
| **Marketing and Merchandise Manager** | Consumer products, campaigns | Draft and localize copy within brand guardrails; analyze campaign performance; automate recurring reports | Workspace, Workflows |
| **Product Engineer** | Builds internal apps | One stable API for many models; agent framework templates; tracing and cost visibility | Gateway, Agent runtime, Observability |
| **Business Automation Builder** | Analyst building without code | Visual workflows connected to approved tools; clear guardrails | Workflows (n8n), Workspace |
| **Platform Administrator** | Platform engineering | Provision teams, budgets and keys; monitor health and spend; manage connectors | Gateway, Infra, Observability |
| **Risk and Compliance Reviewer** | Legal, security, privacy | Risk-tier assignments, audit trails, evidence that controls work, ability to pause a use case | Governance, Observability |
| **Executive Sponsor** | Business unit leader | Adoption, cost and value reporting across teams | Analytics and reporting |

## Jobs to be done (selected)
- When I have an idea for an AI use case, I want to know how to start safely and quickly, so I can show value without a long approval process.
- When I build on AI, I want one API and one set of controls, so I do not rebuild security and cost management for each project.
- When an AI system acts on my behalf, I want to approve consequential actions, so I stay accountable.
- When I review a use case, I want evidence about quality, data handling and cost, so I can approve or pause it with confidence.
- When I report to leadership, I want adoption and value by team, so I can justify continued investment.
